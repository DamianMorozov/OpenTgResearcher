# Руководство по настройке Десктоп версии

## Установка и запуск OpenTgResearcherDesktop под ОС Windows
- Скачайте и запустите инсталлятор [OpenTgResearcherDesktop-win-x64-Setup.exe](https://github.com/DamianMorozov/OpenTgResearcher/releases)
- Нажмите кнопку `Старт`, затем наберите и выполните `OpenTgResearcherDesktop`

## Настройка подключения
Кликните по ссылке справа: https://my.telegram.org/auth?to=apps
Там вы сможете зарегистрировать своё ПО для использования с телеграм.
Введите полученные данные в поля:
- АПИ хеш
- АПИ ИД
- Номер телефона
- Прокси: без прокси (по умолчанию)
- Пароль: если таковой запросит телеграм в сообщении об ошибке доступа (снизу формы)
- Пароль подтверждения: если таковой запросит телеграм в сообщении об ошибке доступа (снизу формы)
- Имя: если таковой запросит телеграм в сообщении об ошибке доступа (снизу формы)
- Фамилия: если таковой запросит телеграм в сообщении об ошибке доступа (снизу формы)
Сохраните ваши настройки.
Кликните по кнопке "Подключиться к ТГ серверу". 

## Парсинг публичного источника без вступления

На странице «Чаты» раскройте «Добавить публичный чат без вступления». В поле «Публичное имя или ссылка» введите `@durov` или `https://t.me/durov` и нажмите «Добавить / открыть».

Программа получит ID и адрес доступа источника через Telegram, проверит чтение истории и откроет пульт чата. Выберите каталог для файлов, проверьте параметры и нажмите «Запустить парсинг чата». Для нового источника сохранение сообщений и файлов включено; повторное добавление сохраняет существующий каталог, позицию и настройки.

Подписка на источник не оформляется. Список «Все» показывает добавленный источник, фильтр «Подписки» — только чаты, в которых аккаунт состоит. Для неизвестного источника одного числового ID недостаточно: требуется публичное имя или ссылка. Если одновременно заданы ID и имя разных источников, парсинг остановится с объяснением.

Доступность публичной страницы не гарантирует доступность всей истории, файлов или списка участников: решение принимает Telegram для подключённого аккаунта. При отказе программа покажет причину. Для приватных чатов сначала получите доступ в самом Telegram; приглашения и ссылки на отдельные сообщения в этой форме не поддерживаются. Добавление внешних источников требует подключения пользовательского аккаунта.
